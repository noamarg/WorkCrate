## Bugs and feature requests

Open a [GitHub issue](https://github.com/noamarg/WorkCrate/issues) and choose a template:

- Bug report
- Feature request
- Documentation

Read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting a pull request. Use **`dev`** as the integration branch (feature PRs → `dev`; releases → `dev` → `main`). Details: [branching and releases](docs/architecture/guides/12-branching-and-releases.md).

## Security

See [SECURITY.md](SECURITY.md). Do not file public issues for vulnerabilities.

## Questions

Use a GitHub issue with a clear title (e.g. “Question: …”) or enable **Discussions** on the repository for Q&A. For product direction, reference relevant `SCN-*` or capability docs when you can.

## Community

Follow the [Code of Conduct](CODE_OF_CONDUCT.md) in all project spaces.
