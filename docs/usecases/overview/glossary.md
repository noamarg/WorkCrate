# Glossary

| Term | Definition |
|------|------------|
| **Module (MOD-01–MOD-13)** | Top-level feature toggle in the admin catalog. MOD-01 is always on; visibility is controlled in Experience Studio. |
| **Sub-pack** | Optional capability bundle inside a module (e.g. `engineering` under Delivery packs). |
| **Experience Studio (MOD-02)** | Admin UI to configure modules, navigation, page layouts, profiles, and publish changes. |
| **Experience profile** | Named set of nav, layout, and section visibility rules assigned to roles, teams, or users. |
| **Published config** | Live org experience after admin publish; users receive per rollout policy. |
| **Work item** | Atomic unit of work; subtypes include task, bug, ticket, request. |
| **Program** | Group of related projects with shared outcomes (portfolios layer on Projects). |
| **Preset** | Industry or job-family starter pack: modules, profiles, templates - not a separate product module. |
| **Scenario (SCN-*)** | Authoritative use-case specification in `docs/usecases/scenarios/`. |
| **Capability guide** | Readable module overview in `docs/usecases/capabilities/`. |
| **Guest** | External user with limited permissions, usually via client portal profile. |
| **Org admin** | User who can manage organization settings, Experience Studio, and delegation. |
