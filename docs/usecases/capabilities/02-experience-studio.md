# MOD-02 - Experience studio

**Module ID:** MOD-02  
**Catalog toggle:** Always on for org admins  
**Status:** draft

## At a glance

- Enable/disable modules MOD-03–MOD-13 safely.
- Control navigation, page visibility, layouts, and sections.
- Define experience profiles and assign to roles, teams, users.
- Setup wizard, industry presets, preview, and publish.

## Problems it solves

One product serves many job types without overwhelming users. Admins tailor WorkCrate to their organization without code.

## Who uses it

| Persona | Typical need |
|---------|----------------|
| Org administrator | Full studio access |
| Delegated configurator | Limited publish rights |

## Admin configuration

- **Catalog:** MOD-02 always available to admins.
- **Typical profiles:** created here (`Engineering`, `Revenue`, `ClientGuest`).
- **Experience Studio:** this module is the studio itself.
